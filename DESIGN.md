# Portfolio design direction

Ali Rayyan is an early-career software engineering student with security internships, a frontend AI engineering internship, and a substantial public project collection. The portfolio helps a hiring reader inspect his work, understand his contribution, and choose the appropriate resume.

## Direction

A technical editorial portfolio: navy typography on cool neutral paper, one restrained coral accent, authentic screenshots, and compact evidence lists. The person's name and professional direction establish identity. Selected projects explain the work; the full repository index supports deeper inspection. Experience is chronological and simulations remain separate from employment.

## Decisions from the supplied brief and guides

- Remove the previous warm/lime palette, marquee, orbit graphics, simulated radar, conceptual CMS, decorative SVG dashboard, oversized closing CTA, badge overload, and tiny uppercase metadata.
- Keep the existing vanilla HTML, CSS, and JavaScript stack. No framework or animation dependency is necessary.
- Use Manrope for headings and readable body text. Metadata is sentence case, at least 12px; body text is 15-17px.
- Limit motion to selected-project entrance transitions, link feedback, and browser-native smooth navigation. Preserve visible content without JavaScript and honor reduced-motion preferences.
- Use the owner's portrait and verified project screenshots only. Where no real screenshot exists, a project narrative and source link are sufficient.
- Use distinct layouts for introduction, selected work, project index, experience, and credentials. Do not turn every section into cards.
- Provide keyboard navigation, clear focus, 44px controls, a functional project search, and explicit empty states.

## Reference review

The supplied Impeccable and Taste repositories were consulted as design guides, not installed as executable tools. The user's brief overrides conflicts such as mandatory animation counts, invented sample content, random palettes, or unrelated stock photography. Brittany Chiang's portfolio was reviewed for readable role/project hierarchy; Brian Lovin's for concise identity and direct project indexing. No layout or copy was copied.

## Color tokens

Ground #F7F8FA; surface #ECEFF3; ink #142235; secondary #506075; accent #B84743; dark field #142235; white #FFFFFF. Accent is limited to key actions and active state. All surfaces use cool neutrals.
